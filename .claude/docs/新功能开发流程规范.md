# 新功能开发流程规范

> 从一个想法到一个可用功能的完整路径。与 dev 流程技能（Claude Code、Qwen Code `/dev`，Codex `$dev`）同构（流程技能是本流程的自动化版）。

## 六步流程

```
1) 需求澄清 → 2) 设计表 → 3) 菜单SQL → 4) 后端六件套 → 5) 前端三件 → 6) 验证与授权
```

### 1. 需求澄清（10 分钟）

回答四个问题：
1. 管什么对象？（→ 表设计）
2. 有哪些字段？哪些是查询条件？（→ Entity + PageParam）
3. 页面什么形态？（普通表格 / 树 / 左树右表 / 主子表）
4. 挂在哪个菜单下？谁能用？（→ SYS_RESOURCE + 角色授权）

### 2. 设计表

按数据库设计规范：`BIZ_` 前缀全大写、String 雪花主键、审计字段组、中文 COMMENT。产出 DDL 并执行。

### 3. 菜单与按钮 SQL

MENU 行（挂到某目录下）+ BUTTON 行（驼峰按钮码）。**这一步常被遗忘**——忘了它，功能再对页面也不显示、按钮全隐藏。（代码生成器"项目内生成"会自动写入菜单和按钮，不要重复执行 SQL。）

### 4. 后端六件套

两种方式二选一（落位默认 snowy-plugin-biz；用户指定时放自建业务插件，新建插件见 plugin-architecture 技能）：

**方式 A：AI 直写**（dev 流程技能默认）——按 crud-development 技能模板逐件生成，先 Read notice 范本再写。

**方式 B：平台代码生成器**——系统 → 在线开发 → 代码生成 → 导入表 → 填 GenBasic（`pluginName=snowy-plugin-biz`（默认值，填 biz 会导致项目内生成失败）、`packageName=vip.xiaonuo`、`moduleName=biz`（生成到自建插件时这三项按该插件填写）、`tablePrefix=Y/N`（是否移除表前缀的开关，默认 Y，只影响自动带出的 busName）、busName、`className`（原样用于类名和文件名，生成器**不会**自动加 Biz 前缀，导入 BIZ_SUPPLIER 时自动带出 BizSupplier，保持即可）、菜单归属、模板形态）→ 生成 → AI 核对修补（落位/URL/权限码；模板自带小诺版权头，自建业务代码不强制，按用户版权规范处理）。详见 code-generator 技能。

### 5. 前端三件

`api/biz/biz{Xxx}Api.js` + `views/biz/{域名}/index.vue` + `form.vue`（可选 detail.vue；自建插件换成 `api/{插件缩写}/`、`views/{插件缩写}/`）。按 frontend-pc 技能模板。

### 6. 验证与授权（本项目无自动化测试基建，验证 = 启动手测）

```
1. 重启后端（新代码 + 若改过白名单必须重启）
2. 前端刷新（npm run dev 热更通常够，路由变了强刷）
3. 系统 → 权限管控 → 角色管理：给测试角色"授权资源"（勾选新菜单和按钮），再"授权权限"（勾选新接口 URL）。**超管角色也要勾**，超管不会自动通过 @SaCheckPermission，手写的新接口不授权超管也 403（代码生成器项目内生成时已自动给超管授权）
4. 用该角色账号登录验证（保存授权后系统会自动刷新在线用户的权限缓存，不用重新登录；已登录的页面刷新一下即可看到新菜单和按钮）
5. 页面走查：新增 → 列表 → 查询 → 编辑 → 删除 → 详情
6. 接口层验证：http://localhost:82/doc.html 带调（边界值/必填校验/权限）
7. check 流程技能规范检查
```

## 无测试基建下的质量保障

项目仅有两个空壳测试类，**不要试图补测试基建**（引入测试体系属框架改动）。质量保障靠：
1. 六件套模板一致性（生成器模板 = 官方规范）
2. check 流程技能 + code-reviewer 静态审查
3. Knife4j 手测清单（上节第 6 步）
4. 提交前 git-workflow 四原则

## 完成后的收尾

- [ ] DDL 增量脚本存档 `_sql/`
- [ ] update-status 流程技能记录进度
- [ ] commit（`【新增】xxx`，格式 `【类别】中文描述`，见 git-workflow 技能）
- [ ] 有后续想法 → add-todo 流程技能

## 常见流程错误

| 错误 | 后果 |
|---|---|
| 忘执行菜单 SQL | 页面不出现 |
| 忘"授权资源" | 菜单不出现 / 按钮全隐 |
| 忘"授权权限" | 接口 403（超管也一样） |
| 改白名单没重启 | 白名单不生效 |
| 授权后没刷新页面 | 前端菜单/按钮还是旧的（后端权限缓存已自动刷新，不用重新登录） |
| 表没审计字段 | 自动填充报错/逻辑删除失效 |
| 直接改平台插件实现功能 | 升级即冲突，业务代码进 biz 或自建业务插件 |
