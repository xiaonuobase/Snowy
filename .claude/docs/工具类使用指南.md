# 工具类使用指南

> 决策树：**Common* 工具 → Hutool → Spring/官方 API → 才自写**。完整索引见 `.agents/skills/common-toolkit`。

## snowy-common 工具类（`snowy-common/.../util/` 目录，数量以实际检索为准）

| 工具类 | 一句话用途 |
|---|---|
| CommonCryptogramUtil | 国密：doSm2Encrypt/doSm2Decrypt/doHashValue/doSm4CbcEncrypt/doSm4CbcDecrypt；加密字段等值查询用 doSm4CbcEncryptCandidates + in |
| CommonValidCodeUtil | 短信/邮件验证码发送限流：checkSendFrequency（同一目标 60 秒一次、每天 10 次，同一 IP 每小时 30 次） |
| CommonSm4CbcTypeHandler | 字段级 SM4 加密（Entity @TableField 用；在 handler/ 包，不在 util/） |
| CommonEmailUtil | 邮箱格式校验（isNotEmail / validEmail）；**不负责发送**，发邮件走 dev-api 的 DevEmailApi |
| CommonDownloadUtil | 文件下载写流 |
| CommonAvatarUtil | 按姓名生成文字头像（generateImg） |
| CommonOtpUtil | OTP 动态口令 |
| CommonSqlUtil | 数据库兼容：safeIn（IN 超过 999 项自动拆分，兼容 Oracle）、scopeIn（数据范围走预计算表子查询）；入参是 LambdaQueryWrapper |
| CommonResponseUtil | 向 response 写错误 JSON（renderError，过滤器场景） |
| CommonFilterExceptionUtil | 过滤器内异常转发到 /errorView 统一处理 |
| CommonServletUtil | Request/Response 获取 |
| CommonKeyUtil | 国密密钥保护：密钥 XOR 混淆存储、运行时 reconstruct 还原；generateSm2KeyPair / generateSm4Key 开发期生成密钥。业务一般不直接调用，缓存 key 用 CacheConstant 常量 |
| CommonIpAddressUtil | IP 归属地（ip2region） |
| CommonUaUtil | 浏览器/系统解析 |
| CommonTraceIdUtil | 链路 traceId |
| CommonTimeFormatUtil | 时间友好化显示：formatWxPastTime（仿微信"x 分钟前"）、formatSeconds（秒转天时分秒）；常规格式化用 hutool DateUtil |
| CommonNetWorkInfoUtil | 网速测量：getNetworkUpRate（采样 2 秒返回上下行速率，监控用）；不提供内外网判断 |
| CommonJoinPointUtil | AOP 参数获取 |

## 非 util 的常用基础类

| 类 | 用途 |
|---|---|
| CommonResult | 统一返回（data/ok/error） |
| CommonException | 业务异常（{} 占位中文消息） |
| CommonEntity | 实体基类（审计+逻辑删除） |
| CommonPageRequest | 分页请求（defaultPage） |
| CommonCacheOperator | Redis 缓存统一操作（底层 RedissonClient，key 自动加 `Cache:` 前缀） |
| CommonDataChangeEventCenter | 数据变更事件广播 |
| CommonTimerTaskRunner | 定时任务接口 |
| DevEmailApi / DevSmsApi | 发邮件 / 发短信（dev-api 跨插件接口，不在 snowy-common；短信只接入阿里云、腾讯云） |

## Hutool 高频（5.8.25，全局依赖）

| 类 | 场景 |
|---|---|
| StrUtil / ObjectUtil / RandomUtil / IdUtil | 判空、随机、ID |
| BeanUtil | **对象转换唯一选择**（toBean/copyProperties） |
| CollStreamUtil / CollectionUtil | 集合流/工具 |
| JSONUtil / JSONObject | JSON、跨插件传值 |
| Convert | 类型转换 |
| DateUtil | 日期 |
| IoUtil / FileUtil | 文件流 |

## 禁止事项

1. 禁止引入 commons-lang3 / guava 等（hutool 已覆盖；出厂 CommonAvatarUtil、GlobalExceptionUtil 里的 lang3 StringUtils 是传递依赖的历史遗留，新代码不要模仿）
2. 禁止手写 MD5/SHA/AES（国密标准走 CommonCryptogramUtil）
3. 禁止重复造轮子（自写前必须查本清单）
4. 禁止Controller 手写下载流（CommonDownloadUtil）
5. 禁止业务代码拼 Redis key（CacheConstant + CommonCacheOperator）

## 自写工具的落位

- 仅本插件用 → 本插件 `core/util/`（如 `snowy-plugin-biz/.../core/util/`）
- 全项目通用 → 提议下沉 `snowy-common/.../util/`（命名 Common{Xxx}Util）
